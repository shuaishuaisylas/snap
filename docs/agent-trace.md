# Snap 轨迹与 AI 说明

适用版本：0.20.0。

在 Agent 右侧“改动”旁打开“轨迹”。输入、模型、工具分成三条泳道，可以按执行顺序或已记录的耗时定位步骤，搜索原始参数和结果，并查看概述、参数、结果、上下文、Schema 与计时。历史未记录的信息不会补造。

顶部“AI说明”默认关闭。打开后，使用当前会话的模型结合任务、公开动作和结果，解释每步做了什么及可能的目的。说明属于根据公开证据的推测，原始记录可独立查看。

已注册 Agent 任务运行时，说明请求排队；空闲后批量生成。成功说明会缓存。关闭开关隐藏说明、取消相关待办与在途请求，保留已保存记录。取消不能撤回模型服务已经处理或计费的请求。

模型说明会带来额外请求和用量，缺少渠道或模型时可能不可用。它不等于模型的隐藏思考，也不能代替对实际文件和业务结果的核对。
